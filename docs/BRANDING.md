# ScaleRules branding

The approved project logo is [scalerules-icon.png](assets/scalerules-icon.png).
It uses a charcoal background, four bright corner dots and a darker central gear.
The gear was darkened by approximately 30% relative to the previous preview;
the approved corner-dot brightness was retained.

The image is displayed in the repository README now. Adoption as the Android
launcher icon is planned for the next app release and has not been applied yet.
For Android, prepare adaptive foreground/background layers and check circular,
squircle and rounded-square masks so the corner dots remain visible.

The logo concept was created for ScaleRules with assistance from OpenAI image
generation. Do not use Tailscale or Tailscale Auto Rules artwork as the launcher.
