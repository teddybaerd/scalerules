# ScaleRules branding

The approved project logo is [scalerules-icon.png](assets/scalerules-icon.png).
It uses a charcoal background, four bright corner dots and a darker central gear.
The gear was darkened by approximately 30% relative to the previous preview;
the approved corner-dot brightness was retained.

The original image is displayed in the repository README. The Android launcher
uses a vector tracing in `ic_launcher_foreground.xml`, a charcoal background and
a dedicated monochrome layer. All four dots fit inside the adaptive icon safe
zone for circular, squircle and rounded-square masks. Density-specific legacy
icons are rendered from [scalerules-launcher.svg](assets/scalerules-launcher.svg).
The flat vector preserves the approved dot and gear contrast without bitmap texture.

The logo concept was created for ScaleRules with assistance from OpenAI image
generation. Do not use Tailscale or Tailscale Auto Rules artwork as the launcher.
