# ScaleRules 0.3.0

## English

- **Three exit nodes:** Failover now supports a primary node, an optional second node and a final backup. Switching back to a preferred node now uses the same timing as switching away.
- **Clearer settings:** Exit-node failover has its own settings page, labeled selection fields and Beta status. Connection rules show the correct page title.
- **Separate journals:** Connection rules and failover each show their own decisions. Clearing one journal preserves the other.
- **DNS recovery:** DNS is checked after automatic switches. Temporary warnings can clear without reconnecting; brief warnings may still occur.
- **More privacy:** Automatic diagnostic uploads to Tailscale have been removed. Local decision journals remain available.
- **Report a bug** now opens ScaleRules GitHub Issues.

**Updating:** Install the APK over your existing ScaleRules installation; do not uninstall first. Accounts, rules and settings are retained. Existing two-node setups keep working. To add a third node, open **Settings → Exit-node failover**.

## Deutsch

- **Drei Exit Nodes:** Failover unterstützt jetzt einen Hauptknoten, einen optionalen zweiten Knoten und einen letzten Ersatzknoten. Die Rückkehr zu einem bevorzugten Knoten verwendet dieselben Zeiten wie das Ausweichen.
- **Übersichtlichere Einstellungen:** Exit-Node-Failover hat einen eigenen Menüpunkt, beschriftete Auswahlfelder und den Status Beta. Verbindungsregeln zeigen den passenden Seitentitel.
- **Getrennte Protokolle:** Verbindungsregeln und Failover zeigen jeweils ihre eigenen Entscheidungen. Das Leeren eines Protokolls erhält das andere.
- **DNS-Erholung:** Nach automatischen Wechseln wird DNS geprüft. Vorübergehende Warnungen können ohne Reconnect verschwinden; kurze Warnungen sind weiterhin möglich.
- **Mehr Datenschutz:** Automatische Diagnose-Uploads zu Tailscale wurden entfernt. Lokale Entscheidungsprotokolle bleiben verfügbar.
- **Fehler melden** öffnet jetzt die GitHub-Issues von ScaleRules.

**Update:** Die APK über die vorhandene ScaleRules-App installieren, nicht vorher deinstallieren. Konten, Regeln und Einstellungen bleiben erhalten. Bestehende Konfigurationen mit zwei Knoten funktionieren weiter. Einen dritten Knoten kannst du unter **Einstellungen → Exit-Node-Failover** ergänzen.
