# ScaleRules 0.2.0

- Eigenes App-Symbol mit Zahnrad und vier hellen Punkten, einschließlich runder und thematischer Android-Symbole.
- Neuer Einstellungsbereich „App-Updates“ mit GitHub-Versionsprüfung und Änderungsprotokoll.
- Update-Hinweise beim Öffnen der App, höchstens einmal täglich; jederzeit abschaltbar für Obtainium.
- Updates herunterladen, später erneut anzeigen oder eine Version überspringen.
- Sicherheitsprüfung von Prüfsumme, Paketname, Version und Signierzertifikat vor der Android-Installation.
- GitHub-Downloads und Obtainium bleiben weiterhin möglich.

## Installation

Die dauerhaft signierte Version 0.1.0 lässt sich direkt aktualisieren. Bitte nicht vorher deinstallieren: Anmeldung, Einstellungen und Regeln sollen erhalten bleiben.

Die integrierte Update-Funktion ist ab dieser Version enthalten. Sie berücksichtigt veröffentlichte stabile GitHub-Releases mit einer passenden APK. Der vollständige In-App-Update-Weg wird mit der darauffolgenden Version geprüft.
