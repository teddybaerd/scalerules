# ScaleRules 0.2.4

## English

- Initial setup no longer automatically requests VPN permission and starts the default provider flow for an unconfigured account. Choose an account or server explicitly from the main screen or Settings → Accounts.
- Show Tailscale sign-in/registration, adding another account, custom server and auth-key actions directly in Accounts. Existing reauthentication and profile switching remain available.
- Explicit Tailscale actions use the official control server on a new profile, rather than inheriting a previously configured Headscale server.
- Show the ScaleRules icon and GitHub repository link in About. Retain upstream license acknowledgements.

Device validation pending: clean install without browser redirection, each account entry, existing Headscale profile switching/reauthentication, About icon/link and signed update preserving rules.

## Deutsch

- Bei einem noch nicht eingerichteten Konto fordert die Ersteinrichtung nicht mehr automatisch die VPN-Berechtigung an und startet den Standard-Anmeldeweg. Konto oder Server bewusst auf der Hauptseite oder unter Einstellungen → Konten auswählen.
- Tailscale-Anmeldung/Registrierung, weiteres Konto, eigener Server und Anmeldeschlüssel direkt unter Konten anzeigen. Erneute Anmeldung und Kontowechsel bleiben erhalten.
- Explizite Tailscale-Aktionen verwenden ein neues Profil mit dem offiziellen Control-Server, statt einen zuvor eingerichteten Headscale-Server zu übernehmen.
- ScaleRules-Icon und GitHub-Link unter Über ergänzt. Lizenzhinweise des Ursprungsprojekts bleiben erhalten.

Gerätetest ausstehend: Neuinstallation ohne Browserweiterleitung, alle Kontooptionen, bestehende Headscale-Konten und erneute Anmeldung, Icon/GitHub-Link sowie signiertes Update mit Erhalt der Regeln.
